# حساب‌کتاب

ربات تلگرام برای حساب‌کتاب خریدهای مشترک دو نفر. خریدها را داخل گروه می‌نویسید، ربات ثبت می‌کند و همیشه نشان می‌دهد **چه کسی چقدر به چه کسی بدهکار است**. خروجی اکسل هم هر وقت خواستید داخل گروه و (در ریپوی خصوصی) داخل گیتهاب ذخیره می‌شود.

## استفاده

فقط یک‌بار `/start` بزنید تا منو بیاید. از آن به بعد **همه‌چیز دکمهٔ شیشه‌ای است**؛ لازم نیست دستوری حفظ کنید.

- **➕ ثبت خرید** — چهار مرحله، هر مرحله یک صفحه:
  1. مبلغ (کیبورد عددی با دکمه‌های ۰–۹، ۰۰، ۰۰۰ و پاک‌کردن)
  2. شرح (یک متن کوتاه؛ روی همان پیام ربات ریپلای کنید، یا «بدون شرح»)
  3. چه کسی پرداخت کرد
  4. حساب کیست: همه حساب یکی از دو نفر، نصف‌نصف، یا سهم‌بندی دقیق (مبلغ یا درصد با کیبورد)

  قبل از ثبت نهایی خلاصه نشان داده می‌شود و هر مرحله دکمهٔ بازگشت و لغو دارد.
- **⚖️ تراز** — چه کسی چقدر به چه کسی بدهکار است
- **🗒 لیست** — آخرین ثبت‌ها
- **💸 تسویه** — «تسویه کامل» یا مبلغ دلخواه؛ لمس دوباره دکمه، تسویهٔ تکراری ثبت نمی‌کند
- **↩️ حذف آخرین ثبت من** — با پرسش تأیید
- **📊 اکسل**، **✏️ تغییر نام**

اولین کسی که هر دکمه‌ای را بزند عضو حساب می‌شود (حداکثر دو نفر)؛ نفر سوم پیام روشن می‌گیرد. «ادمین ناشناس» گروه می‌تواند منو بسازد، ولی ثبت‌نام با شناسهٔ واقعی‌اش به‌محض اولین دکمه انجام می‌شود.

## راه‌اندازی (یک‌بار)

1. توجه: فایل اکسل و `exports/data.json` (مبلغ‌ها و شرح خریدها) داخل ریپو ذخیره می‌شود؛ اگر ریپو عمومی است یعنی برای همه قابل دیدن است.
2. در **Settings → Secrets and variables → Actions** این Secretها را بسازید:
   - `BOT_TOKEN` — توکن ربات از BotFather
   - `CLOUDFLARE_API_TOKEN` — توکن API با دسترسی *Workers Scripts: Edit* و *D1: Edit* (قالب «Edit Cloudflare Workers»؛ حتماً چک کنید ردیف D1 هم Edit باشد و اگر نبود اضافه کنید)
   - `CLOUDFLARE_ACCOUNT_ID` — شناسهٔ حساب Cloudflare
   - `GH_PAT` *(اختیاری، برای دستور «اکسل» داخل گروه)* — توکن fine-grained گیتهاب فقط برای همین ریپو با دسترسی *Actions: Read and write*
3. **Actions → Deploy → Run workflow**. این کار دیتابیس را می‌سازد، ربات را دیپلوی و webhook را تنظیم می‌کند. از این به بعد هر پوش روی `main` خودکار دیپلوی می‌شود.
4. در BotFather: `/mybots` → ربات → *Bot Settings* → *Group Privacy* → **Turn off**، سپس ربات را یک‌بار از گروه حذف و دوباره اضافه کنید (یا ربات را ادمین گروه کنید). بدون این، تلگرام پیام‌های عادی گروه را به ربات نمی‌دهد.
5. یک نفر در گروه `/start` بزند تا منو بیاید؛ بعد هر دو نفر هر دکمه‌ای را بزنید تا ثبت‌نام شوید.

> اگر توکن ربات جایی عمومی نوشته شده، در BotFather با `/revoke` عوضش کنید و Secret را به‌روز کنید.

## اکسل

- دستور `اکسل` (نیاز به `GH_PAT`) یا **Actions → Export Excel → Run workflow** فایل را می‌سازد و داخل گروه می‌فرستد.
- `exports/hesabketab.xlsx` و `exports/data.json` هم داخل ریپو کامیت می‌شود (تاریخچهٔ گیت = نسخه‌های قبلی). هر شب ساعت ۰۰:۰۰ تهران هم اگر داده عوض شده باشد خودکار انجام می‌شود.
- برگهٔ «خلاصه» با فرمول زنده از برگهٔ «رکوردها» حساب می‌شود؛ ردیف را ویرایش کنید، تراز به‌روز می‌شود.

## ساختار

- `src/index.js` — Worker (webhook تلگرام، دکمه‌ها، خروجی داده)
- `src/lib.js` — منطق خالص: کیبورد عددی، سهم‌بندی، تراز، تاریخ شمسی (تست‌شده در `test/`)
- `migrations/` — دیتابیس D1
- `scripts/make_xlsx.py` — ساخت اکسل
- `.github/workflows/` — `deploy.yml` و `export.yml`

## نحوهٔ محاسبه

هر ردیف: «چه کسی پول را داده» + «سهم هر نفر». تسویه هم همین شکل است (گیرنده «سهم» کل مبلغ را دارد). تراز هر نفر = جمع پرداختی‌ها − جمع سهم‌ها؛ نفر مثبت بستانکار است. حذف‌ها (`void`) در دیتابیس می‌مانند ولی حساب نمی‌شوند.

محدودیت‌ها: فقط دو نفر، مبلغ‌ها تومان و عدد صحیح، ربات داخل هر چتی که اعضا آن را بنویسند جواب می‌دهد (گروه یا پیوی).
